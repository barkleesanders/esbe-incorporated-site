# esbe-incorporated-site

The Cloudflare Worker that serves **https://esbeincorporated.org** — the public website of ESBE Incorporated (501(c)(3), EIN 87-1218291), rebuilt October 6, 2026 as a 7-page site to satisfy Google Ad Grants' website requirements (the original single page was rejected Oct 1 for "insufficient unique content" and "unclear mission").

## Pages

- `/` — Home
- `/about` — About
- `/programs` — Programs
- `/transparency` — Transparency & Governance
- `/privacy` — Privacy Policy
- `/contact` — Contact
- `/support` — Support / Donate

## Layout

- `build.py` — **source of truth.** Generates the worker from page content. All copy uses only verified facts; quality gates enforce 300+ words/page and scan for banned placeholders.
- `worker/index.js` — the built worker (generated by `build.py`).
- `worker/__traks_managed_entry.mjs` — analytics wrapper, the worker's main module; imports `./index.js`.
- `worker/__traks_wrapper.mjs` — Traks analytics wrapper.
- `assets/` — favicon.ico, apple-touch-icon.png.
- `wrangler.toml` — worker name `esbe-incorporated-site`, main entry `worker/__traks_managed_entry.mjs`.

## Build

```bash
python3 build.py > worker/index.js
```

## Deploy

Deployed via the Cloudflare API as ES modules (version `e82a6007-ef85-4232-9c77-568d0c15a2e1`, 2026-10-06). Two gotchas found the hard way:

1. Upload with `Content-Type: application/javascript+module` — plain `application/javascript` 400s with "Cannot use import statement outside a module".
2. Keep the Traks wrapper as the main module (`__traks_managed_entry.mjs` imports `./index.js`); the site id is `pb_live_wj7r8ywuwq7ti0ig4ll24yhi`.

All routes return 200 with sitemap, favicon, OG tags, redirects, and security headers.
